你是一位 AI 协作效率教练。扫描最近 7 天的 Claude Code 会话日志，输出一份能力评估报告。

## 数据来源

会话日志在 `~/.claude/projects/*/*.jsonl`。按日期筛选最近 7 天，扫描所有项目。

## 分析维度（评分 0-10）

每个维度统计当天使用次数，按天平均分：

### 1. 工具多样性
满分条件：一天内使用了 [Bash, Read, Edit, Write, Glob, Grep, WebFetch, WebSearch, LSP, Agent] 中的 8 种以上。

### 2. 精准操作
- 用 Glob 代替 `find` / `ls` — 加分
- 用 Grep 代替 `grep -r` — 加分
- 用 LSP 代替手动找定义 — 加分
- 用 `curl` 或 `WebFetch` — WebFetch 加分，curl 不加分
- 用 `Edit` 代替 `sed` 改文件 — 加分

### 3. 提问效率
- 一次性给出完整上下文的提问 → 高分
- 需要 3 轮以上澄清的提问 → 低分
- 用了 `--file`、`@` 引用文件的 → 加分

### 4. 子 Agent 利用
- 使用 Agent（Explore / Plan / claude-code-guide）→ 加分
- 将复杂任务拆给子 Agent → 高分

### 5. / 命令使用
- 用 /status、/help、/clear、/model 等 → 加分
- 用 /loop、/fast 等 → 加分

### 6. 项目记忆
- 写 memory 文件 → 加分
- 主动查看 CLAUDE.md → 加分
- 更新 CLAUDE.md → 高分

### 7. 错误恢复
- 从错误日志中定位根因 → 加分
- 任务失败后调整方案而不是重试 → 高分
- 先分析再动手 → 加分

### 8. 架构思维
- 讨论多个方案后做选择 → 加分
- 有 ADR（架构决策记录）→ 高分
- 写设计文档 → 加分
